BOOKFORGE - README IMAGES (2026-10-20, BookForge 1.6.1)

Every picture here was made by BookForge 1.6.1 itself: screenshots of the real window, and pages and sheets
rendered from the real PDFs it made. Nothing was drawn by hand except the labels around them.

The example book "The Lighthouse Clockmaker" (text, title and cover pictures) was written and drawn for
these examples, so you can use it freely in the repository. It is in example-book\ if you want people to try
it themselves (open the .md file as the source).

To use a picture in your README, put this folder in the repository (for example as docs/images) and link
it, for example:  ![The Output step](docs/images/screenshots/07-step-7-output.png)

NOTES
- In the "Original size" column, pages bigger than their space run into each other. That is what BookForge
  prints with that setting (it never shrinks pages); use it only for pages that are already the right size.
- The printing-sheet pictures show the first printed side of the first sheet. BookForge prints each
  signature's innermost sheet first, which is why the first sheet shows pages from the middle.
